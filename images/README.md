# 学习文档图片处理约定

## 保存和引用

1. 保留用户提供的原图，不要擅自改成文本图、重新绘制或生成替代图片。
2. 图片统一保存到仓库根目录的 `images/` 中。
3. 先检查聊天附件是否提供可读取的文件路径或可下载的附件 ID。有可用原文件时直接保存到此目录。
4. 当前任务使用云端 `/workspace/ray`；Mac 上的 `/Users/...` 路径不代表云端能够读取。聊天中看得到图片，也不代表工具能取得原文件。无法取得时，不要让用户反复发送同样的图片。
5. 本次有效的替代流程：用户在 GitHub 的 `work` 分支进入 `images/`，通过 **Add file → Upload files** 上传原图并提交；随后在云端执行 `git pull --ff-only origin work` 获取文件。
6. 在 Markdown 中引用图片，删除被替换的文本架构图，保留相关说明。提交检查通过后，按用户授权提交和推送。

## 显示失败时

- 检查原文件已提交到目标分支，确认路径、大小写和文件格式正确。
- 检查原图地址是否返回成功状态及正确的图片类型。
- 云端能访问不代表用户浏览器能访问；需要区分 Codex 内置浏览器和外部 Chrome / Safari 的加载情况，以及原图域名的网络可达性。
- 不要在没有证据时断言是缓存、相对路径或浏览器问题，也不要反复盲目更换链接。
